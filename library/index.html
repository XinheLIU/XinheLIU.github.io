Depth-First Search & Backtracking <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6"></path><polyline points="15 3 21 3 21 9"></polyline><line x1="10" y1="14" x2="21" y2="3"></line></svg>

Depth-first search walks a graph/tree all the way down before backing up. **Backtracking is DFS over a tree you build on the fly** — the tree is implicit, branches are *choices*, and leaves are *solutions*. When you "backtrack", you undo the last choice and try the next branch.
